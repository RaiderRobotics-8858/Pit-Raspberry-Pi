# FRC MatchMaker Privacy Policy

**Last updated: September 8, 2026**

FRC MatchMaker is an independently developed software application that creates, organizes, and publishes individual FIRST Robotics Competition match videos to YouTube.

This Privacy Policy explains how FRC MatchMaker uses YouTube API Services and Google account authorization.

## YouTube API Services

FRC MatchMaker uses the YouTube Data API to perform publishing and management functions for the FRC MatchMaker YouTube channel.

These functions may include:

* Uploading match videos
* Updating video titles, descriptions, tags, and visibility
* Uploading custom thumbnails
* Creating and maintaining playlists
* Adding videos to event and team playlists
* Checking YouTube video processing status
* Reading basic information about the authenticated YouTube channel

FRC MatchMaker uses Google OAuth 2.0 authorization for API operations that require access to the authenticated YouTube account.

## Information Accessed

FRC MatchMaker accesses only the YouTube account information and permissions required to perform its publishing functions.

Depending on the operation being performed, this may include:

* YouTube channel identification and basic channel information
* Video information
* Playlist information
* Video processing status
* Authorization credentials required to perform permitted YouTube API operations

FRC MatchMaker does not request access to unrelated Google services such as Gmail, Google Drive, Google Calendar, or Google Contacts.

## Information Collected From Users

FRC MatchMaker is currently an operator-run publishing application and does not provide public user accounts or user registration.

FRC MatchMaker does not collect personal information from members of the public who view published videos or playlists on YouTube.

FRC MatchMaker does not sell personal information.

FRC MatchMaker does not sell, rent, or provide Google account information obtained through YouTube API Services to advertisers, data brokers, or other third parties.

## Authentication Data

Google OAuth credentials used by FRC MatchMaker are maintained for the purpose of allowing the authorized operator to access YouTube API Services.

Authentication credentials are not intentionally shared with third parties.

FRC MatchMaker does not store Google account passwords.

## Data Storage

FRC MatchMaker maintains local publishing state needed to manage previously published matches and prevent duplicate uploads.

This state may include information such as:

* YouTube video IDs
* YouTube playlist IDs
* Playlist membership IDs
* Video publication status
* Video processing status
* Thumbnail publication status
* Locally generated metadata used for published match videos

FRC MatchMaker does not use YouTube API data to create advertising profiles or track users.

## Data Retention and Deletion

FRC MatchMaker retains publishing information only as needed to operate and maintain the FRC MatchMaker publishing workflow and to comply with applicable YouTube API Services policies.

Authorization to access the Google/YouTube account can be revoked at any time through Google's security settings page:

[https://security.google.com/settings/security/permissions](https://security.google.com/settings/security/permissions)

If authorization is revoked, FRC MatchMaker will no longer be able to access the authorized YouTube account through the revoked credentials.

Following revocation, FRC MatchMaker will delete or refresh stored YouTube API data associated with the revoked authorization as required by applicable YouTube API Services policies.

Locally stored OAuth credentials associated with FRC MatchMaker can also be deleted by the operator to remove the application's stored authorization.

Requests to delete data associated with FRC MatchMaker may be submitted using the contact information below. Such requests will be handled in accordance with applicable YouTube API Services policies.

Deleting data stored by FRC MatchMaker does not delete data stored by YouTube. YouTube content must be deleted or managed through YouTube or another authorized YouTube API client that supports those actions.

## Public YouTube Content

Videos, playlists, titles, descriptions, thumbnails, and other material published by FRC MatchMaker may be publicly visible on YouTube.

Once content has been published to YouTube, its availability and handling are also governed by YouTube and Google's applicable policies and terms.

## Third-Party Services

FRC MatchMaker uses YouTube API Services provided by Google LLC.

FRC MatchMaker may also include links to publicly available FIRST Robotics Competition information supplied by third-party services such as The Blue Alliance. Those services maintain their own privacy policies and terms.

## Children's Privacy

FRC MatchMaker is not designed to collect personal information from children.

The application publishes robotics competition match footage and related match information. It does not provide public user accounts, messaging, profiles, or other mechanisms intended to collect personal data from event participants or viewers.
